Sommaire (menu d'ancres) construit automatiquement à partir des titres de la page marqués pour le sommaire.

Pour qu'un titre apparaisse dans le sommaire, ajoutez sur le core/heading : "displaySummary": true et "summaryLabel": "Libellé court" (sinon le texte du titre est utilisé). Sans aucun titre marqué, le sommaire est vide.

- "orientation" : "horizontal" (défaut) ou "vertical", "justification" : "left", "center", "right".
- "labelMenuMobile" : libellé du bouton sur mobile.

Placez-le en haut de page ou dans une colonne latérale ; combinez-le avec eo-blocks/sticky pour un sommaire flottant.
